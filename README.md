# Optio

Optio is a modern appointment management platform designed for small and medium-sized businesses.

## Project Status

In development.

## Technologies

### Frontend
Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod

### Backend
Python, FastAPI, SQLAlchemy, Pydantic, Alembic, PostgreSQL, JWT

### Infrastructure & Tools
Docker, Git, GitHub, RESTful API, CI/CD
